# React + Vite Category Page Project

## Project Overview

In this project, we will create a simple **Category Page** using **React**. The page will display various categories such as Technology, Health, Business, and Lifestyle. Each category will have a card displaying:

- The category name
- A brief description
- An image representing the category

This project will help you understand:

1. **How to use components in React**
2. **How to work with arrays and loop through them**
3. **How to pass props between components**
4. **How to display images dynamically in React**

## Project Structure

The project consists of the following components:

### 1. **CategoryContainer**

The `CategoryContainer` component is responsible for displaying all the categories. It holds an array of categories, and for each category, it renders a `CategoryCard` component.

### 2. **CategoryCard**

The `CategoryCard` component is responsible for rendering individual category details. Each card will display:

- A category image
- The category name
- A description of the category
